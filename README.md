# بوصلة 🧭

وكيل ذكاء اصطناعي محاور يرشد طلاب **نظم المعلومات الإدارية** إلى المسار الوظيفي الأنسب لهم من بين ثمانية مسارات، اعتمادًا على استبيان قصير ومعادلة توافق موزونة.

مشروع مقرر **نظم معلومات إدارية متقدمة** – جامعة الطائف.

## الفكرة

يجمع الوكيل معلومات الطالب في خمسة أسئلة قصيرة (المستوى الدراسي، ودرجات المعايير السبعة، والمهارات الحالية)، ثم:

- يحسب نسبة التوافق مع المسارات الثمانية بالمعادلة: `نسبة التوافق % = (Σ وزن المعيار × درجة الطالب) × 2`.
- يرتب المسارات ويصنّفها: ممتاز (80% فأكثر)، وجيد (65–79%)، ومتوسط (50–64%)، وضعيف (أقل من 50%).
- يطبق قواعد القرار: إذا كان الفرق بين أول مسارين 5% أو أقل يطرح سؤالًا حاسمًا ويتوقف حتى يجيب الطالب، وإذا كانت كل النسب أقل من 50% ينصح ببناء الأساسيات أولًا.
- يقدّم عند الطلب: تحليل الفجوة، وخطة الأشهر الستة (مبتدئ أو متقدم)، والشهادات ومصادر التعلم المجانية، والمقارنة بين مسارين، ومقابلة تجريبية.

## مزايا الواجهة

- **لغتان**: أيقونة 🌐 في الترويسة تبدّل بين العربية (RTL) والإنجليزية (LTR)، ويُحفظ الاختيار. ويمكن فتح الإنجليزية مباشرة بإضافة  إلى الرابط. والنسخة الإنجليزية من الدليل في  ترجمة أمينة للأصل العربي، والأصل العربي هو المرجع.
- **الوضع الساطع والداكن**: أيقونة القمر/الشمس، ويتبع إعداد الجهاز تلقائيًا ما لم يختر الطالب.
- **شريط تقدّم** يوضح السؤال الحالي من خمسة، و**زر نسخ النتيجة** لمشاركتها.

## لماذا هو موثوق؟

- **منطق القرار حتمي**: الحساب والتصنيف وقواعد القرار مكتوبة بالكود (`engine.js`)، لا بنموذج لغوي، لذلك النتائج صحيحة دائمًا وقابلة للاختبار.
- **لا معلومة مختلقة**: ملفات `data/*.json` تُولَّد آليًا من ملفات Word الرسمية بالأمر `npm run build:data`، واختبار `tests/data.test.js` يتحقق من أن كل نص فيها موجود حرفيًا في الملفات الأصلية.
- **مجاني بالكامل**: صفحة ثابتة بلا خادم ولا أي API مدفوع ولا مفاتيح، وبلا تسجيل دخول.
- **فهم العامية**: `nlu.js` يطبّع النص العربي (التشكيل والهمزات والتاء المربوطة والألف المقصورة) ويفهم الوصف بالعامية السعودية أو الفصحى أو الإنجليزية، مثل: "أحب الأرقام مرة" = 5، و"البرمجة شوي" = 2.

## هيكل المشروع

```
├── index.html            الصفحة (RTL)
├── styles.css            الهوية البصرية (كحلي وذهبي، وخطا Cairo وAlmarai)
├── app.js                واجهة المحادثة (اللغة والوضع والتقدّم)
├── i18n.js               نصوص الوكيل والواجهة بلغتين
├── bot.js                آلة حالات المحادثة (بلا اعتماد على المتصفح)
├── engine.js             الحساب والتصنيف وقواعد القرار (دوال نقية)
├── nlu.js                تطبيع النص واستخراج الدرجات وكشف النوايا
├── data/
│   ├── matrix.json       مصفوفة الأوزان (8 مسارات × 7 معايير)
│   ├── paths.json        من bosla_paths_guide.docx
│   ├── questionnaire.json من bosla_questionnaire.docx
│   ├── faq_limits.json   من bosla_faq_limits.docx
│   ├── keywords.json     مرادفات للمطابقة فقط (لا معلومات معرفية)
│   └── en/               الترجمة الإنجليزية لملفات الدليل والاستبيان والأسئلة الشائعة
├── source/               ملفات Word الرسمية (قاعدة المعرفة)
├── scripts/
│   ├── build-data.mjs    توليد data/*.json من ملفات Word
│   ├── docx.mjs          قارئ docx بلا مكتبات
│   └── serve.mjs         خادم محلي بسيط
└── tests/
    ├── engine.test.js    اختبارات الحساب (T1–T5 والحدود)
    ├── nlu.test.js       اختبارات العامية واستخراج الأرقام والنوايا
    ├── bot.test.js       سيناريوهات المحادثة بلا متصفح
    ├── data.test.js      التحقق من عدم اختلاق أي معلومة
    ├── i18n.test.js      تطابق الترجمة مع الأصل وسلوك الوكيل بالإنجليزية
    └── e2e.spec.js       Playwright على الجوال (360×740) واللابتوب
```

## التشغيل محليًا

يتطلب [Node.js](https://nodejs.org) الإصدار 20 أو أحدث.

```bash
npm install            # مرة واحدة (لـ Playwright فقط)
npm run serve          # ثم افتح http://localhost:4173
```

## الاختبارات

```bash
npm test                         # اختبارات الوحدة والمحادثة (Node)
npx playwright install chromium  # مرة واحدة
npm run test:e2e                 # سيناريوهات المحادثة في المتصفح
```

## تحديث قاعدة المعرفة

عدّل ملفات Word داخل `source/` ثم شغّل:

```bash
npm run build:data
npm test
```

## النشر على GitHub Pages

1. ارفع المشروع إلى مستودع عام على GitHub.
2. من **Settings ← Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يصبح الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

لا يحتاج الموقع إلى أي إعداد إضافي لأنه صفحة ثابتة.

توصيات "بوصلة" إرشادية، ومبنية على إجاباتك وعلى معايير محددة. القرار النهائي لك، وننصحك باستشارة المرشد الأكاديمي أو أصحاب الخبرة في المجال.
